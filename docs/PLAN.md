# 项目计划：Relay Highlighter

> 本文件是项目的"长期记忆"。换 agent、换窗口、隔很久再回来，都先读这里。
> **只有 Claude（审查者）修改本文件**，Muse 等编码 agent 不要改 `docs/`。

## 1. 目标

用户日常同时开两个窗口（左右分屏或两个窗口），一边是 Muse，一边是 ChatGPT / Codex / Claude Code 等 AI。
每次一边完成回复后，用户要把结果复制粘贴到另一边。中途走开回来后，经常忘了"最新结果在哪一边、该往哪边贴"。

**插件要解决的问题：**

- 哪一侧的 AI 刚刚完成了最新回复，**哪一侧整个网页显示红框**，另一侧没有红框。
- 用户把内容复制到另一侧并**发送**后，红框消失；等另一侧回复完成，另一侧亮红框。
- 用户回来一眼就能看出：红框在哪边，就从哪边复制，贴到另一边。

## 2. 范围

**范围内**

- 浏览器里的网页版 AI 界面（目前确认：`muse.ai`、`chatgpt.com`、`claude.ai`）。
- 红框提示、跨页面同步状态、回复完成检测、发送后清除、极简设置。

**范围外（暂不做）**

- 终端或桌面应用里的 AI（插件无法看到它们）。
- 自动复制粘贴、自动发送内容（只提示，不替用户操作）。
- 联网、账号、数据上传、任何遥测。

## 3. 技术决策

| 项目 | 决定 | 原因 |
|---|---|---|
| Manifest | MV3 | Chrome 当前标准 |
| 后台脚本 | 不使用 service worker | 内容脚本 + `chrome.storage` 事件足以同步 |
| 权限 | 仅 `storage` | 最小权限 |
| 站点范围 | 目前匹配 `muse.ai`、`*.muse.ai`、`chatgpt.com`、`claude.ai`；新增站点逐个确认后添加 | 最小权限，减少误触 |
| 红框实现 | Shadow DOM 里的 `position: fixed` 元素，`pointer-events: none` | 不受页面样式影响，不挡点击 |
| 状态存储 | `chrome.storage.local`，键 `relay.latest` | 多页面共享，监听 `onChanged` |
| 页面实例 ID | `sessionStorage` 里存随机 UUID | 同一标签页刷新后 ID 不变 |
| 回复完成检测 | MutationObserver + 内容静止约 1.5 秒防抖 | 流式输出没有统一的"结束"事件 |
| 站点识别 | 每站一个适配器，另有通用兜底适配器 | 各站 DOM 不同，且会变 |
| 手动快捷键 | `Option+Shift+R`（Mac）/ `Alt+Shift+R`，用 `event.code === "KeyR"`，捕获阶段，忽略长按 | 当前用于手动标记；自动检测完成后保留为手动兜底 |
| 语言/框架 | 原生 JavaScript，无构建步骤、无第三方依赖 | 方便审查，直接加载测试 |

## 4. 状态模型

`chrome.storage.local` 中键 `relay.latest`：

```json
{ "id": "<页面实例 UUID>", "site": "<location.hostname>", "ts": 1700000000000 }
```

规则：

1. 页面 X 检测到"回复完成" → 写入 `relay.latest = {id: X, ...}`。
2. 每个页面监听变化：`latest.id === 自己的 id` → 显示红框，否则隐藏。
3. 页面 X 检测到用户"发送了消息" → 清除 `relay.latest`（红框全部消失）。
4. `relay.latest` 为空时，所有页面都不显示红框。

## 7. 审查清单（Claude 用）

- manifest 是否合法的 MV3，权限和站点匹配是否最小。
- 是否有 `eval`、远程脚本、`innerHTML` 拼接用户内容等风险写法。
- 红框是否影响点击、滚动、页面布局；是否使用最高层级 z-index。
- 选择器是否过于脆弱；是否有通用兜底。
- 是否会被光标闪烁、打字机动画等噪音误触发"完成"。
- 重复注入、页面 SPA 跳转后是否仍然正确。
- 是否保存了页面内容（不应该）。

## 9. 已知限制与经验

- 在 Chrome 里"复制标签页"会连 `sessionStorage` 一起复制，两个标签页可能拿到同一个实例 ID，从而同时亮红框。暂不处理。
- 重新加载扩展后，已打开页面里原来的红框会残留到页面刷新；更新扩展后需要刷新相关页面。
- **重新安装（先 Remove 再加载）会让 Chrome 清空"网站访问"授权**：需要到扩展详情页的 Site access 里把各站点开关重新打开，再刷新页面。只点卡片上的刷新按钮不会丢授权。
- 页面进入全屏（视频等顶层元素）时红框可能被盖住；iframe 内不显示红框。
